# ============================================================================
# H5 CHANGES SUMMARY
# ============================================================================
#
# NwTt.ned:
#   - ethIf: EthernetInterface → LayeredEthernetInterface + EthernetStreamingPhyLayer
#   - Added ethLi: MessageDispatcher with serviceMapping = {"ethernetmac": "ethIf"}
#   - encap.registerProtocol = false (avoid ethLi conflicts)
#   - Connections: ethIf ↔ ethLi ↔ translator, encap ↔ ethLi
#
# DsTt.ned:
#   - tsnEth: EthernetInterface → LayeredEthernetInterface + EthernetStreamingPhyLayer
#   - ueEth: EthernetInterface → LayeredEthernetInterface + EthernetPhyLayer (non-streaming)
#   - Added tsnLi, ueLi: MessageDispatchers with serviceMapping
#   - Connections: interfaces ↔ dispatchers ↔ translator
#
# NwTtTranslator.cc:
#   - registerProtocol(Protocol::ethernetMac) in INITSTAGE_LOCAL
#   - registerService for encap on nl in INITSTAGE_NETWORK_LAYER
#
# DsTtTranslator.cc:
#   - registerProtocol(Protocol::ethernetMac) on both gate pairs
#   - DispatchProtocolReq + DirectionTag on outgoing packets
#   - FCS value 0xC00DC00D for LayeredEthernetInterface compatibility
#
# .ini files:
#   - Removed EthernetInterface overrides and promiscuous settings
#   - Added streaming PHY for Device B: *.tsnDeviceB[*].eth[*].phyLayer.typename
#
